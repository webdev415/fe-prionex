**Дата:** 2026-07-07 · **Статус:** утверждён по макету (v5), в разработке (Слой 0)

**Репозитории:** `fe-prionex` (фронт), `prionex-assistant` (мозг/контракт), `api-prionex/services/ai-assistant` (прокси-relay)

---

## 1. Контекст и цель

У AI-ассистента операторов взыскания два режима: `fast` (быстрый ответ) и `thinking` (модель рассуждает вслух, вызывает инструменты как оркестратор). Панель раздумий во фронте **уже реализована** inline (`ReasoningStream` + `renderReasoningPanel` в `AiAssistantBetaPage.tsx`), но: (а) живёт внутри бабла и растягивает ответ; (б) раздумья и источники не связаны с конкретными фактами; (в) ссылки на клиента некликабельны; (г) раздумья эфемерны — не сохраняются.

**Цель:** превратить раздумья в *рабочий инструмент оператора* — компактный ответ + богатая боковая панель «Активность» (как в ChatGPT Pro), где виден ход оркестратора, каждый факт кликабелен и ведёт к своему источнику, клиенты открываются из чата, а к раздумьям диалога можно вернуться и пометить, что было верно/неверно.

Богатый UX — **только для `thinking`**. Для `fast` поведение не меняется (быстро — трейс не нужен).

## 2. Модель взаимодействия (утверждена макетом v5)

- **Ответ компактный.** Под ним — плашка `«Ход рассуждения · N шагов · Xс»` + последняя строка мысли. Плашка НЕ растягивает ответ.
- **Плашка = toggle.** Клик открывает боковую панель «Активность» справа; повторный клик, крестик вверху или Esc — закрывают. Шеврон-индикатор поворачивается.
- **Панель «Активность» справа:** fixed, выезжает справа, **ширина регулируется** перетаскиванием левого края (340–760px, состояние в zustand с persist). Содержит: секцию «Шаги оркестратора» (лента шагов: мысль → инструмент → результат, статусы running/ok/error) и секцию «Ход рассуждения» (читаемый текст). На экране `< 1024px` — панель на весь экран/bottom-sheet с backdrop.
- **Факт-как-ссылка:** каждое число/дата/сумма/статус в ответе (①②③④) кликабельно → открывает панель и разворачивает соответствующий шаг-источник (SQL+строки / Python-код / страница договора), подсвечивая факт.
- **Клиенты — часть результата.** Когда ответ содержит клиента или выборку клиентов, каждый — валидная ссылка на карточку (`/dashboard/clients/{id}`), открывается прямо из чата, без копирования id. Длинная выборка скроллится внутри ответа. Отдельного «механизма выборки» нет — это обычная часть ответа.
- **Пометки на раздумьях:** у шагов — кнопки ✓верно/✕неверно (оценка отдельного шага, а не только 👍/👎 на весь ответ). Плашка «сохранено» — раздумья привязаны к диалогу, к ним можно вернуться.
- **Только просмотр.** Оператор читает раздумья и источники, но не выгружает данные должника с собой. Экспорт в PDF — в настройках, по решению админа (по умолчанию выключен).

## 3. Архитектура по слоям

Каждый слой — отдельная ветка/PR с тестами и независимым ревью. Слои упорядочены по риску и зависимости от бэка.

### Слой 0 — Панель-оркестратор справа `[фронт only, текущий контракт]` ← в разработке
Вынести существующую inline-панель в боковую «Активность» справа: компактная плашка-toggle, resizable, крестик/Esc, мобильный fallback, `dockGeometry` right-offset. Переиспользовать `ReasoningStream`/`renderToolStep`. Сохранить все `data-testid`. **Ничего в бэке не меняем** — работает на текущих SSE-событиях `reasoning`/`tool_start`/`tool_end`.

### Слой 1 — Факт-как-ссылка (citations) `[бэк + фронт]`
Новый контракт «факт ↔ источник» по лекалу Anthropic Citations API. Реалистичный путь для локальной Gemma — **конвенция маркеров** (как уже сделано для `>> уточнения:` / `followups` в `chat_service.py`):
- Модель в ответе ставит сноски `[[1]]`, `[[2]]` у обосновываемых фактов.
- Бэк парсит их (аналог `parse_followups`) и эмитит новое SSE-событие `citations: [{id, tool_use_id, kind: 'sql'|'calc'|'crm'|'doc', table?, query?, ref?}]`, вырезая маркеры из чистого текста.
- Фронт (`MarkdownMessage` custom renderer, паттерн `CodeRenderer`/`TableRenderer` L141-216) превращает сноски в кликабельные ①②③, клик → панель разворачивает шаг с этим `tool_use_id`.
- SSOT события — `prionex-assistant/docs/ASSISTANT_MODES.md`.

### Слой 2 — Детали источника в панели `[бэк + фронт]`
Сейчас `tool_end` несёт только 200-символьный `result_preview`. Добавить структурный результат шага (первые N строк JSON + сам SQL/код) — либо в расширенный `tool_end`, либо в `citations`. Фронт показывает в развёрнутом шаге: SQL-запрос + строки таблицы (подсветка нужной), Python-код расчёта + результат.

### Слой 3 — Client deep-links + клиенты в результате `[фронт, лёгкий бэк]`
Имя/`client_id` в ответе и выборки клиентов → ссылки на маршрут карточки в CRM. Фронт: renderer для client-ссылок (из `citations kind='crm'` или из markdown-конвенции `[client:48213|Коваленко]`). Открытие — React Router на существующий маршрут карточки клиента. Выборка: до ~5 видимых в чате со скроллом, полный список — часть ответа.

### Слой 4 — PDF `[бэк + инфра, тяжёлый]`
Два независимых куска:
- **Документы клиента как источник:** новый read-only инструмент `mcp__crm__get_document` → document storage client-service (AES-256-GCM). Регистрация в `registry.py` + whitelist в `tool_policy.py`. Факт ④ (пеня) → страница договора. Гоча: сканы без OCR-слоя не citable по странице.
- **Генерация PDF-отчёта:** добавить `.pdf` в `ARTIFACT_EXTENSIONS` расчётного инструмента + reportlab. Только для «просмотр/приобщить», не для выгрузки оператором.

### Слой 5 — Персистентность + аннотации `[бэк]`
Сейчас `reasoning`/`toolSteps`/`sources` эфемерны (не переживают F5). Чтобы к раздумьям диалога можно было вернуться:
- Прокси (`api-prionex/services/ai-assistant`) персистит `reasoning_summary`/`citations`/`step_marks` в свою БД (расширить `Message`/`ToolCall` схему; `_StreamTee.observe` сейчас их игнорирует).
- Пометки ✓верно/✕неверно шагов → новое событие/эндпоинт (аналог feedback `POST /api/feedback`), пишутся в журнал → топливо для D4-самообучения мозга. Закрывает «faithfulness problem» (Anthropic): человек помечает, где раздумье не соответствовало факту.

## 5. Безопасность и приватность

- **PII-дисциплина:** раздумья могут содержать ПДн должника — не выгружаются оператором (только просмотр); экспорт PDF за флагом админа. `pii_guard` мозга уже маскирует ПДн в журнале.
- **Faithfulness-дисклеймер:** «раздумья — черновой ход мысли модели, не факт» + пометки верно/неверно (по рекомендации Anthropic про visible thinking).
- **Read-only:** ни один слой не добавляет write-инструментов; `mcp__crm__get_document` (Слой 4) — строго read-only под правами вызывающего (JWT/RBAC), не сервисный супер-токен.
- **Данные — не команды:** содержимое источников в панели оборачивается как данные (анти-инъекция, `_render.wrap_untrusted` уже есть).
